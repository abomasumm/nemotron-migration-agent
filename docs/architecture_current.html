Current pipeline

You write a brief. Claude Opus plans it into tasks and wakes only for decisions. Cheap models on OpenCode Go and GOAT build, test and review each task through omp and 9router, and nothing merges into main until the gates pass and you merge it yourself.

  • Claude Pro, official CLI only
  • OpenCode Go pool
  • GOAT pool
  • Scripts and you

How it works

  • Decisions: Claude Opus plans goals into tasks, triages stuck tasks and signs off risky ones. It is woken only when events wait, at most 10 times a day.
  • Building: each task gets tests that must fail on the old code, then two workers from different model families; a judge picks one.
  • Checking: gates run tests, lint, typecheck, scope and security; a model from another family reviews the change.
  • Routing: every non-Claude call goes through omp, then 9router, into the Go or GOAT pool, with fallbacks when a pool is full.
  • Merging: passing tasks merge into the agents branch. Only you merge it into main.
